# FRENCHUG

Русскоязычный сайт Ярослава Алексеевича об алгоритмической торговле. Astro + TypeScript + GSAP / ScrollTrigger. Полностью статическая сборка; не требует платных API или серверной базы для просмотра.

## Запуск

Требуется Node.js 22.12+ (рекомендуется 24).

```sh
npm ci
npm run dev
```

Проверка и сборка:

```sh
npm run check
npm run build
npm run preview
```

## Cloudflare Pages

Подключить этот репозиторий → Framework preset Astro → команда `npm run build` → каталог `dist`.
Переменная `SITE_URL` = окончательный адрес сайта, например `https://frenchug.pages.dev` (после создания заменить на реальный адрес). `BASE_PATH=/`. На Pages произойдёт пересборка при каждом коммите в main. Секретов для текущего сайта нет. Для Direct Upload можно загрузить содержимое `dist` из ZIP с готовой сборкой.

Для собственного домена задать `SITE_URL=https://ваш-домен`, пересобрать. Этот адрес используется в canonical, sitemap, robots и Open Graph.

## GitHub Pages

Приложен workflow `.github/workflows/pages.yml`. В Settings → Pages выбрать Source: GitHub Actions, затем запустить workflow. Он собирает с `BASE_PATH=/frenchug/`. Конфигурация Cloudflare не изменяется. Деплой требует включённого Pages на стороне GitHub.

## Страницы

- `/` — основной путь в публичный Telegram.
- `/stats/` — статус подтверждённых данных и методология.
- `/signals/` — формат, пример, $73 / 30 дней, FAQ и отключённое оформление.
- `/terms/`, `/privacy/`, `/subscription/` — предварительные условия, требуют утверждения владельцем.
- `/risks/` — риски торговли.

## Что готово и что ждёт подключения

Работают навигация, ссылки на https://t.me/frenchug, мобильное меню, FAQ, адаптивная вёрстка, анимации, SEO-файлы и сборка.

Оплата Platega, технический Telegram-бот, Рината, D1, выдача и отзыв доступа **не подключены**. Платёжных запросов и фальшивого успеха нет. Кнопка оформления disabled. Перед продажами нужны утверждённые условия и реквизиты исполнителя, проверка платёжного сценария и подтверждённые webhook-события. Архитектурный план — `docs/INTEGRATIONS.md`.

Статистика намеренно отсутствует до проверенной выгрузки. `src/data/stats.json` — место для данных; `docs/STATS.md` описывает требования к публикации. Включение verified без реализации проверенной публикации останавливает сборку.

Клики вызывают локальное событие `frenchug:analytics`; внешняя аналитика и cookies не подключены. После добавления адаптера необходимо актуализировать политику конфиденциальности.

## Дизайн и движение

Чёрный / белый / розовый / золото. Оригинальные геометрические объекты и SVG выполнены кодом. Сборка hero по строкам; CSS 3D знак F; параллакс знака и золотых элементов; лента; раскрытие манифеста по словам; sticky-заголовок процесса и синхронные шаги; поворот визуализаций; разнесённые слои Telegram; движение финальной стрелки; микроанимации кнопок. При reduced-motion скролл-эффекты выключаются, весь контент остаётся видимым. На мобильных sticky-подача заменяется последовательными сценами.
