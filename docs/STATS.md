# Публикация статистики

Сейчас публичные результаты отсутствуют. Ранее сообщённые в переписке значения не считаются подтверждённым журналом.

1. Получить полный экспорт реальных исполнений (без API-ключей и идентифицирующих аккаунт данных).
2. Зафиксировать период, часовой пояс, валюту, комиссии/финансирование, пополнения/выводы и частичные исполнения.
3. Разделить реальные сделки, демо и бэктест в отдельных наборах.
4. Рассчитать чистый реализованный PnL, количество закрытых сделок, Win Rate и maximum drawdown с явно названной методикой; R:R не подменять процентом прибыльных сделок.
5. Добавить проверенную таблицу и график на /stats с доступной текстовой альтернативой и ссылкой на очищенный источник.
6. Данные и расчёты проверить, только затем разрешить verified. Текущий build guard требует осознанного внедрения компонента публикации.

Публичный интерфейс не принимает произвольную загрузку файла посетителем, чтобы пользовательские данные не выглядели авторскими подтверждёнными результатами.
